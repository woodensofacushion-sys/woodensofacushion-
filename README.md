# Wooden Sofa Cushion — Fashable-style storefront

Static website built from the service photo RAR folders supplied in this chat.

## Included
- Mobile-first storefront layout inspired by the supplied reference screenshots
- Wine/magenta + blue accent palette, category circles, search, service cards and mobile bottom navigation
- 7 service collections from the supplied RAR photos
- Click-to-open image viewer with a searchable service description for every photo
- SEO meta tags, canonical URL, Open Graph tags, LocalBusiness JSON-LD, FAQ content, robots.txt and sitemap.xml
- Tawk.to live chat script already included
- Phone/WhatsApp enquiry buttons

## Deploy
Upload the contents of this folder to the root of the GitHub Pages/Cloudflare Pages project.
Do not upload the RAR files for the website itself; the images are already extracted into `assets/services/`.
